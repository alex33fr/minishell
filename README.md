# minishell

## Description

Minishell is a project designed to create a simple shell. The goal is to develop a functional command-line interpreter inspired by Bash. This project provides extensive knowledge about process management using forks and signals, as well as handling file descriptors and pipes.

## Instructions

### Compilation

The project includes a **Makefile** that compiles the source files with the `-Wall -Wextra -Werror` flags using `cc`. To compile the program, run the following command in your terminal:
```
make
```
This will produce the minishell executable.

### Execution

Run the shell by executing the following command:

```
./minishell 
```
